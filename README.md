# trCIRIT

**A bioinformatics tool for backward translation identification and validation.**

## Features

**trCIRIT** is an integrated pipeline for investigating circRNA-derived translation, optimized for **batch processing on Linux**. Key features include:

- circRNA identification from transcriptome data via **CIRIT**
- Construction of **custom protein references** from full-length circRNAs, with built-in circRNA-derived ORFs to support downstream MS search
- Validation of translation events through a **two-round MaxQuant search**:
  - First  search against the linear mRNA reference
  - Then re-searching **linear-free library** against the circular RNA reference 
- Comprehensive **analysis of MaxQuant results** for confident peptide identification
- Compatible with circRNA predictions from other tools

The **built-in circRNA reference** and **linear-free search strategy** are tailored for the relatively **low-abundance and weak-signal** of circRNA translation. By eliminating interference from linear transcripts, this design improves sensitivity, enhances specificity, and reduces false positives—enabling more accurate detection of circRNA-derived peptides.

## Installation

```bash
git clone git@github.com:Yin-HJ/trcirit.git
cd trcirit
conda env create -n trcirit -f conda_trcirit_env.yml
conda activate trcirit
pip install -e .
```

## Usage

```bash
trcirit -h
Usage: trcirit [OPTIONS] COMMAND [ARGS]...

  A bioinformatics tool for backward translation identification and validation.

Options:
  -h, --help  Show this message and exit.

Main Modules:
  analyze   Analyze MS search results generated by the Validate module.
  build     Find potential circRNA ORFs and build reference for MS search.
  identify  Identify, re-construct and annotate the full-length circRNAs.
  validate  Validate circRNA-derived peptides via a two-round MaxQuant search.

Tools:
  merge-circ   Find and merge shared full-length circRNAs generated by different algorithms.
```

## Example

### Step 1: identify full-length circRNAs

```bash
trcirit identify -h
Usage: trcirit identify [OPTIONS]

  Identify potential circRNA from FASTA file, re-construct and annotate the full-length circRNAs.

  Example: trcirit identify -i transcript-150.fa -w 10 -r chm13.bed -g chm13.fasta -D
  genome/build/chm13 -d chm13 -o ident_out/ -p prefix

Options:
  -i, --input PATH            Input FASTA file  [required]
  -p, --prefix TEXT           Prefix for output files, defaut: prefix of input file
  -o, --out_dir DIRECTORY     Output directory, default: ident_out
  -w, --window INTEGER        Window/seed (integer), initial search for CIRIT. default: 10
  -r, --genome-ref FILE       Genome reference (BED)  [required]
  -g, --genome-seq FILE       Genome sequence (FASTA)  [required]
  -d, --genome-index TEXT     Genome database name, created by gmap_build -d option  [required]
  -D, --genome-dir DIRECTORY  Genome directory, created by gmap_build -D option  [required]
  --java-path PATH            Custom path to Java executable. default: auto-detect from PATH
  -h, --help                  Show this message and exit.
```

 #### Preparation for using identify module

```bash
# build index by Gmap
cd trcirit/data/genome
gmap_build -d chm13 chm13.fasta -D build
```

 #### Identify  full-length circRNAs 

```bash
cd trcirit
trcirit identify -i transcript-150.fa -w 10 -r chm13.bed -g chm13.fasta -D
  genome/build/chm13 -d chm13 -o ident_out/ -p prefix
```

- Input FASTA file was generated by transcriptome assembly tool, such as IDBA, trinity.
- The identify module is implemented through CIRIT.

### Step 2: build reference

```bash
  --java-path PATH         Custom path to Java executable. default: auto-detect from PATH

```

#### Find potential ORFs and build reference for MS search

```bash
trcirit build -i trCIRIT_full-length.fa -o build_out -p prefix
```

### Step 3: validate translation peptides

This step consists of a two-round MaxQuant workflow: an initial search against a linear mRNA reference, followed by raw-to-mzML conversion, high-confidence spectra filtering, mzXML conversion, and a second search against a circRNA reference.

<font color=Crimson>!Due to a lack of vendor-provided raw data access libraries, only MS raw data generated by Thermo Fisher Scientific is currently supported. </font>

```bash
trcirit validate -h
Usage: trcirit validate [OPTIONS]

  Validate circRNA-derived peptides via a two-round MaxQuant search.

  1) Search raw files against linear mRNA reference; 2) Extract high-confidence spectra; 3) Remove
  matched spectra from raw files; 4) Re-search against circRNA-derived peptide reference.

  Example: trcirit validate -f config.yaml

Options:
  -f, --config PATH        YAML config file for pipeline  [required]
  -o, --out_dir DIRECTORY  Output directory, default: valid_out
  -d, --dryrun             Dry run mode: only generate mqpar.xml and print commands without
                           execution
  -s, --skip-generate      Skip generating mqpar.xml files (if manually modified after --dryrun)
  -h, --help               Show this message and exit.
```

#### Preparation for using validate module

experiment design

```
# trcirit/data/ms_template/exp_design_tpl.txt

RawFileName	Experiments	Fractions
file1.raw   Disease1 
file2.raw   Disease2    
file3.raw   Control1

file5.raw   Disease3    1
file6.raw   Disease3    2
```

Configuration file

```
# trcirit/data/ms_template/config.yaml 

# === Required parameters ===
Required:
  # raw ms data path
  rawFilePath: ./tests/codetest/rawFilePath
  
  # linear mRNA reference
  fastaFilePath_linear: ./data/reference/uniprotkb_AND_reviewed_true_AND_model_o_2024_11_29.fasta
  # circular RNA referece generated by build module
  fastaFilePath_circ: ./data/reference/HCC_pep.fa
  
  # MaxQuant mapar.xml template path
  template: ./data/ms_template/mqpar_tpl.xml

  # expriement design file
  exp_design: ./tests/codetest/exp_design.txt


# === Optional parameters ===
Defaults:
  # !!! you need to check the relative path !!! 

  # MaxQuant project name, it is recorded in mqpar.xml - <name>
  projectName: my_test

  # maxquant path 
  mq_cmd: ./pkgs/MaxQuant_v2.6.7.0/bin/MaxQuantCmd.dll
  
  # msconvert path
  pwiz_path: ./pkgs/pwiz/msconvert

  # ThermoRawFileParser path
  trfp: ./pkgs/trfp/ThermoRawFileParser.exe
  
  # scan filter paramters
  pep_thresh: 0.01
  score_thresh: 0.7

  # num of threads
  threads: 40
 
# === MaxQuant search settings ===
Recommended:
  enzymes:
    - Trypsin/P
  fixedModifications: 
    - Carbamidomethyl (C)
  maxMissedCleavages: 2
  firstSearchTol: 20
  mainSearchTol: 4.5
  minPeptideLength: 7
  minRatioCount: 2
```

#### validate translation by two-round MaxQuant search

```
trcirit validate -f config.yaml
```

- Template file could be found at trcirit/data/ms_template/

#### (Optional) personalize editing profiles using the --dryrun and --skip-generate 

<font color=crinson>**!Attention**: If you want to edit the mqpar configuration file required by MaxQuant's execution more personally, you can generate the configuration file using the --dryrun option and modify it manually. After that, use --skip-generate to run the edited configuration file. </font>

```bash
trcirit validate -f config.yaml --dryrun -o valid_out
# go to out directory and modify the mqpar.xmls
trcirit validate -f config.yaml --skip-generate -o valid_out
```

### Step 4: analyze results

```bash

  Analyze MS search results generated by the Validate module.

  Example: trcirit analyze -i valid_out -o anlyz_out

Options:
  -i, --input PATH         Module Validate output directory  [required]
  -o, --out_dir DIRECTORY  Output directory, default: anlyz_out
  -h, --help               Show this message and exit.
```

#### Analyze MaxQuant results

```
trcirit analyze -i valid_out -o anlyz_out
```

- The analysis is mainly based on proteinGroups.txt and peptide.txt from valid_out/linear_free/combined/txt/
